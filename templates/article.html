有时，我们需要的并不是更多的答案，而是一点安静下来的时间。走出熟悉的节奏，留意光线如何落在桌面，风如何经过窗边，想法又如何在某个不经意的时刻慢慢成形。

01 / 从一个小小的观察开始

{% if post.category == '技术手记' %}写代码之前，我习惯先在纸上写下问题。输入是什么，想得到什么结果，哪些步骤其实可以省略？把复杂的任务拆成清楚的小步骤，往往比立刻打开编辑器更有效。{% elif post.category == '设计灵感' %}观察一件日常用品，是练习设计感受力的好方法。它的边缘为什么是圆的？颜色为什么停在这里？真正舒服的体验，常常来自这些被认真考虑过的小事。{% elif post.category == '漫游日记' %}出发的那天没有详细的行程。山脚的路有一点潮湿，树叶在阳光下透出浅浅的金色。我们沿着溪流走，没有急着抵达某一个地方，也就看见了更多平时会错过的风景。{% else %}我开始试着为一天留出一点没有安排的空白。不听播客，不查看消息，只是喝水、散步，或者看一会儿窗外。这些看似没有产出的片刻，反而让我重新听见自己的想法。{% endif %}

把注意力还给当下，把时间留给真正重要的事。

02 / 留一点空白，让想法生长

我们很容易把每一分钟填满，却忘了留白本身也是生活的一部分。一个没有被立刻解决的问题，一页还没有写完的笔记，一场没有目的地的散步，都可以成为新的开始。

试着记录今天让你停下来的一件小事。不必完整，不必漂亮，也不必急着分享。写下它，是为了让自己记得：普通的日子里，也有值得珍惜的东西。

慢慢来，我们下篇见。
